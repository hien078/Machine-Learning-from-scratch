# Mathematical Foundations

Reusable mathematical toolboxes that multiple ML topics depend on.

## Sections

| Section | Description | Key Concepts |
|---|---|---|
| [Linear Algebra](linear_algebra/README.md) | Vectors, matrices, projections, eigenvalues, SVD | Projection, least squares, spectral decomposition |
| [Calculus & Optimization](calculus_optimization/README.md) | Derivatives, gradients, Taylor, optimization | Chain rule, gradient descent, convexity |
| [Probability & Statistics](probability_statistics/README.md) | Distributions, expectation, MLE, MAP | Bayes' theorem, maximum likelihood |
| [Information Theory](information_theory/README.md) | Entropy, cross-entropy, KL divergence | Shannon entropy, mutual information |
| [Numerical Computing](numerical_computing/README.md) | Floating point, stability, vectorization | IEEE 754, condition numbers, NumPy |

## How to Use

- Read the `.md` files for pure definitions and concepts
- Open the `.ipynb` files for computation, demos, and verification
- Topics in `topics/` reference these foundations — start here if the math is unfamiliar
